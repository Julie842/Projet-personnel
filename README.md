# Projet-personnel

Projet personnel : ajouter une tâche

Une application web simple, fluide et responsive de gestion de tâches (To-Do List) développée en HTML5, CSS3 et JavaScript.

🔍 Aperçu du projet :
Cette application permet d'ajouter des tâches à faire, de les marquer comme terminées grâce à des cases à cocher, et de les supprimer. Elle gère automatiquement le défilement (scrollbar) dès que la liste dépasse une certaine hauteur.

✨ Fonctionnalités :
Ajout de tâches : saisie via le champ texte et ajout avec le bouton "Add" ou par pression de la touche Entrée.
Validation des entrées : message d'alerte empêchant l'ajout de tâches vides.
Marquer comme complétée : cocher la case raye le texte et grise la tâche.
Suppression : bouton avec icône de corbeille (Unicons) pour retirer individuellement chaque tâche.
Défilement dynamique : gestion automatique de l'overflow (max-height: 300px) avec une barre de défilement personnalisée aux couleurs de l'interface.

🛠️ Technologies utilisées :
HTML5 : Structure sémantique de l'application.
CSS3 : Flexbox pour le centrage et la mise en page, styles sur-mesure pour la scrollbar webkit.
JavaScript (ES6) : Manipulation dynamique du DOM et gestion des événements (keyup, click, change).
Unicons Iconscout : Bibliothèque d'icônes vectorielles pour l'icône de suppression.
